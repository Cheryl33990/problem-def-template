# 目錄收斂與遷移檢查

基準：main commit `095629b3f670202ea8e5149db65b03ee8a0076b3`。本紀錄屬於模板維護，不是衍生專案的驗收結果。

## 遷移對照

| 原用途 | 新位置與處理 |
|---|---|
| 根目錄開始說明、使用指南與 HTML 路線圖 | 合併成 [使用指南](../workflow/guide.md)，不維護重複入口 |
| 根目錄流程、review 與 meta 規則 | docs/workflow/reference |
| 各階段空白文件 | docs/workflow/templates；不預建實際專案階段 |
| 實作與測試空目錄 | 根目錄 src、tests；既有專案沿用自身框架 |
| 每個專案的起始狀態 | docs/project/brief.md、progress.md |
| 教學案例 | docs/workflow/examples |
| 模板變更紀錄、改進與試跑計畫 | docs/template-maintenance |
| 工具專屬 AI 規則 | 移除副本，共用根 AGENTS.md |

原有實作目錄只有空目錄標記及示意設定，沒有應用程式或可執行測試。移除只有註解的語言／環境設定，不預設 Python 或領域工具。
階段索引 README 的共通操作已整合進指南和範本索引；保留有實質契約的設計子目錄說明。

## 使用行為與相容性

- 起步只有 brief 與 progress，允許模糊目標與未知；使用者不用先填滿 PRD。
- 規劃、實驗、驗證與復盤可先記兩份文件；複雜時才拆分。
- 範本連結供瀏覽；實例化時須改 Markdown、正文及 YAML 的路徑，不能拿空範本當證據。
- 既有專案不得整包覆蓋 README、AGENTS、CI 或真實紀錄；先記錄路徑對照。
- 舊目錄連結不再保留相容轉址。既有書籤、外部腳本或未合併分支須按用途更新。
- PR #3 已先合併；本分支已整合其 main commit `f31f3ace18d9624294e651f052d5a64f8fb5afba`。保留實驗狀態、生產／探索 prompt、schema 決策與追溯說明修正，並將其流程檢查紀錄移入本維護目錄。

## 檢查範圍

發布前檢查全部檔案清單、Markdown 相對連結目標、frontmatter 邊界、舊路徑與工具專屬規則殘留，並確認指南與規則不依賴模板維護資料。
逐項走讀模糊目標起步、既有專案整合、按需建立紀錄、移除模板維護資料四種情境。
這些是文件靜態檢查與流程走讀，並非真實使用者試跑；複製範本後的連結仍須由操作者更新。
沒有應用程式可供執行測試，也未新增 CI。真實案例驗證仍待後續進行。

Review 先讀根 README、使用指南、AGENTS，再檢查範本索引與此遷移說明。完整改動以 PR diff 為準。

整合 PR #3 後共 49 個檔案；158 個 Markdown 相對連結的檔案或目錄目標皆存在（排除範例程式區塊與 HTML 註解，未宣稱驗證所有段落錨點）。文件 frontmatter 邊界與三個必要欄位檢查通過。起始專案紀錄恰為兩份，根目錄文件恰為 README 與 AGENTS；使用區對模板維護區無連結依賴。舊編號目錄路徑及工具專屬規則檔引用掃描無殘留。

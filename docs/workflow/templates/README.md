# 按需取用的範本庫

這裡保存空白結構，不是使用者專案的紀錄。日常先用 [brief](../../project/brief.md) 和 [progress](../../project/progress.md)；有需要才複製下列檔案。
複製後按 [使用指南](../guide.md) 重新定位每個連結、正文與 YAML 路徑，填入真實內容；不要把本目錄的範本當成已確認證據。

| 用途 | 入口 |
|---|---|
| 詳細問題定義、範圍與驗收 | [PRD](problem/PRD.md)、[AC](problem/acceptance.md)、[角色](problem/stakeholders.md)、[非目標](problem/non_goals.md) |
| 探索 | [探索筆記](discovery/NN_template.md) |
| 方法比較 | [候選方案](approach/options.md)、[比較矩陣](approach/tradeoffs.md) |
| 重大決策 | [ADR](decisions/TEMPLATE.md) |
| 技術設計 | [tech spec](design/tech_spec.md)、[schema](design/schema/README.md)、[pipeline](design/pipeline/README.md)、[生產 prompt](design/prompts/README.md) |
| 測試規劃 | [策略](testing/test_strategy.md)、[資料](testing/fixtures.md)、[AC 規格](testing/acceptance_tests/TEMPLATE.md) |
| 當次測試結果 | [驗證紀錄](testing/validation/TEMPLATE.md) |
| 假設實驗 | [實驗資料夾](experiments/EXP_TEMPLATE/README.md) |
| 收尾 | [完成清單](closure/done_checklist.md)、[復盤](closure/retrospective.md) |
| 複雜資訊管理 | [資料盤點](meta/data_inventory.md)、[風險](meta/risks_and_assumptions.md)、[追溯](meta/traceability.md)、[術語](meta/glossary.md)、[prompt 記錄](meta/prompt_log.md) |

完整文件的內容要求見 [slot contracts](../reference/slot_contracts.md)。只檢查本輪已使用的內容；未使用範本不用升狀態、填完 TODO 或建立對應目錄。

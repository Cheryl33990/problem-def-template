# 當次驗證紀錄範本 

> **範本庫文件**：需要時才複製到專案紀錄區。本檔連結供瀏覽範本；複製後須改為實際專案文件，未建立的依賴標待建立或連到 brief。做法見 [使用指南](../../../guide.md)。

> 複製後改為 draft，填完轉 in-review；未跑就寫未跑，不勾通過。

- 日期／執行者：
- 範圍／AC：
- 被測分支與 commit（工作目錄有未提交變更也記錄）：
- 環境／工具版本／依賴／資料快照：
- 前置條件：
- 實際命令或人工步驟：
- 預期結果與事前門檻：
- 實際結果、輸出與證據位置：
- 判定：通過／失敗／未跑／不適用（附理由）：
- mock、取樣與其他限制：
- 失敗原因假設、處理與需重跑範圍：
- 對應 PR／review／追溯條目：

不同 AC 可逐條展開。結果檔 approved 代表紀錄已審閱，不代表測試通過；以「判定」欄為準。

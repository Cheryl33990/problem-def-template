# Prompt 歷史日誌 

> **範本庫文件**：需要時才複製到專案紀錄區。本檔連結供瀏覽範本；複製後須改為實際專案文件，未建立的依賴標待建立或連到 brief。做法見 [使用指南](../../guide.md)。

本檔記錄專案中所有「值得復盤的 prompt 嘗試」——含 Claude Code session、實驗中的模型 prompt、以及對人類的指示。
目的是讓未來的人或 AI 在類似情境下不必從零摸索。

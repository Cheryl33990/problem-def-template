# AI 工具與能力參考

本文件提供選用工具的原則，不代表任何工具已安裝，也不要求使用者先建立工具清單。所有 AI 工具共用根目錄的 [AGENTS.md](../../../AGENTS.md)；若工具不會自動讀取，請在開始時明確請它閱讀。

## 依工作需要選用

| 工作 | 需要的能力 | 成果位置 |
|---|---|---|
| 釐清模糊目標 | 訪談、區分事實與假設 | brief |
| 資料探索 | 讀取來源、確認品質與限制 | brief，必要時建立 discovery |
| 方案與設計 | 比較替代方案、說明取捨 | brief，重大決策另建 ADR |
| 開發與測試 | 修改程式、執行實際可用的測試 | 原有程式與測試目錄；progress 記證據 |
| Review 與驗證 | 對照成功標準、檢查差異與結果 | progress，必要時建立 validation |

使用前確認目前環境的工具名稱、權限、能力及限制。工具不可用時，直接處理可完成的部分，並說明缺少的證據，不宣稱已執行。

## 何時建立專案工具清單

只有工具環境會影響重現或交接時，才在專案 progress 記錄工具、版本、確認日期與限制。清單過長再抽成 `docs/project/meta/skill_registry.md`，由 progress 連結；不要修改這份共用參考來存放專案狀態。

只有影響結果、需要重現的提示詞或工具失敗才另留紀錄，不逐輪保存所有對話。不因本表自動安裝工具、啟用多代理或增加權限。

參考：[使用指南](../guide.md)、[工作成果契約](slot_contracts.md)。

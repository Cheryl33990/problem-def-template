# 60_experiments/

本資料夾收錄**實驗紀錄**。每個實驗一個獨立資料夾，便於回溯與比較。

## 內容

| 路徑 | 用途 |
|---|---|
| [EXP_TEMPLATE/](EXP_TEMPLATE/) | 實驗範本，新增實驗時整個資料夾複製 |

## 命名與流程

- 資料夾命名：`EXP-NNN-short-title/`（NNN 為三位數流水號）
- 內含至少三份：`README.md`（hypothesis → conclusion）、`prompt.md`、`analysis.md`
- status 流轉：`draft`（規劃中）→ `in-review`（已執行待結論）→ `approved`（結論已採用）→ `archived`（結案）
